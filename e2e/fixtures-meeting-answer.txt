=== 부서: ceo-advisor | 한결 (CEO Advisor) ===
핵심 판단: MEMORY 모드는 진행합니다. 지금 게임에 없던 "실패"와 "아깝다"는 감정을 만들어 보상형 광고가 들어갈 자리를 자연스럽게 만들기 때문입니다.
근거: 기존 100개 레벨, 정답 검증기, 난이도 분석을 그대로 쓸 수 있어 추가 비용이 작습니다. 한 판이 짧아 반복 플레이에도 유리합니다.
대안: (1) 숫자 가리기 방식(추천) (2) 정답 경로를 보여주고 따라 그리기 방식. (2)는 추론이 사라져 금방 단조로워지므로 제외합니다.
가장 큰 위험: 재미 검증 전에 광고부터 붙이는 것. 순서는 재미 검증 → Android → 광고로 고정합니다.

=== 부서: validator | 서진 (Business Validator) ===
핵심 판단: 조건부 GO. 아이디어 자체는 검증할 가치가 있지만 아직 사용자 데이터가 0입니다.
근거(확인함): 1→N 숫자를 한 줄로 잇는 게임은 이미 여러 개 있습니다(예: Zip – Connect the Numbers, Sequence Grid Connect). 숫자를 보여준 뒤 가리고 순서대로 누르는 기억 게임도 있습니다(Math Memory Games의 Hidden Order). 한 번의 검색에서는 "기억한 뒤 경로를 잇는" 조합을 찾지 못했습니다. 다만 이것이 "없다"는 증거는 아니며, 스토어 출시 전에 한 번 더 확인합니다.
대안: 차별점 문구는 "외우고, 잇는다(기억 + 길찾기)"로 두고 테스트합니다.
가장 큰 위험: 기억 게임은 너무 어려우면 광고를 보기 전에 이탈합니다.
판단 기준(대표가 정하는 기준, 시장 데이터 아님): 테스터 5~10명 중 절반 이상이 "한 판 더 하고 싶다"고 답하면 다음 단계로 갑니다.

=== 부서: cto | 도윤 (CTO) ===
핵심 판단: 1~2일이면 프로토타입이 가능합니다(추정). 기존 CLASSIC 코드를 건드리지 않고 MEMORY 모드를 별도로 추가합니다.
확정 사양:
- 미리보기 시간: 3×3=3초, 4×4=5초, 5×5=7초, 6×6=10초. 설정 객체 한 곳에서 바꿉니다.
- MEMORY v1에는 3×3~6×6 레벨만 씁니다. 7×7·8×8은 테스트 결과를 보고 결정합니다.
- 시간이 끝나면 숫자를 가립니다. 1과 목표 숫자 칸은 계속 보입니다. 고른 칸은 숫자가 드러납니다.
- 틀린 칸 3회면 실패, "다시 도전" 화면을 띄웁니다.
- "다시 보기 +3초"는 레벨당 1회 무료. 광고 호출 자리(AdManager.requestRewarded('memory_peek'))만 함수로 분리하고 광고는 연결하지 않습니다.
- 기록: 레벨별 성공·실패, 다시 보기 사용, 클리어 시간을 localStorage에 저장합니다.
가장 큰 위험: 중복된 NumberMaze-Web 폴더. 작업 전에 최신 폴더 하나로 정리해야 합니다.

=== 부서: pricing | 하린 (Pricing Strategist) ===
핵심 판단: 수익 구조는 "무료 플레이 + 이용자가 원할 때만 보는 보상형 광고"로 확정합니다.
광고 지점(확정): (1) 다시 보기 +3초 (2) 틀린 곳부터 이어하기. "숫자 하나 공개" 힌트는 테스트 데이터를 보고 추가합니다.
근거: 다시 보기 버튼을 누르는 횟수가 곧 광고 노출 가능 횟수입니다. 테스트에서 이 숫자를 먼저 측정합니다.
수익 계산은 공식만 씁니다: 월 광고 수익 = 월 활성 이용자 × 1인당 보상형 광고 시청 수 × 광고 단가. 광고 단가는 연결 전까지 알 수 없어 숫자를 넣지 않습니다.
대안: 광고 제거 + 무제한 다시 보기 유료 상품은 이용자가 생긴 뒤 검토합니다.
가장 큰 위험: 이용자 수가 작으면 광고 수익도 작습니다. 월 100만원 목표에 광고만으로 닿을지는 데이터 전까지 미확정입니다.

=== 부서: sales | 민재 (Sales Manager) ===
핵심 판단: B2C 광고 모델이라 영업 업무는 작습니다. 테스터 모집을 맡습니다.
제안: 지인·커뮤니티에서 테스터 5~10명을 모읍니다. 개인정보는 받지 않고 링크만 공유합니다. 테스트가 끝나면 "몇 판 했는지, 언제 그만뒀는지, 한 판 더 하고 싶은지" 세 가지만 묻습니다.
대안: 학원·교사용 "기억력+수 순서" 학습지 판매(B2B)는 MEMORY 모드 결과를 본 뒤 별도 검토합니다.
가장 큰 위험: 지인 테스터는 실제보다 좋게 답합니다. 말보다 기록(플레이 횟수, 다시 보기 사용 수)을 더 믿습니다.

=== 부서: marketing | 유나 (Marketing Manager) ===
핵심 판단: 홍보 문구의 중심은 "5초 보고 외워서 잇는 숫자 미로"입니다.
제안: (1) 첫 판 30초 플레이 영상을 숏폼으로 만듭니다(출시 후). (2) "나는 6×6을 몇 초에 외웠다" 같은 결과 공유 화면을 나중에 추가합니다.
대안: 친구 도전 링크(같은 판을 친구에게 보내기)는 2차 기능으로 둡니다.
가장 큰 위험: 테스트 전 홍보는 하지 않습니다. 재미가 확인되기 전에는 외부에 알리지 않습니다.

=== 부서: bookkeeper | 지호 (Bookkeeper) ===
핵심 판단: 이번 단계 비용은 0원으로 확정합니다(무료 도구와 기존 코드만 사용).
기록할 것: 앞으로 생길 비용 후보는 Google Play 개발자 등록비, 도메인·호스팅입니다. 금액은 결제 시점의 공식 안내를 보고 기록하며, 지금 추정 금액은 넣지 않습니다.
광고 수익이 생기면 실제 입금액만 "실제" 거래로, 예상치는 "시뮬레이션"으로 따로 기록합니다.
가장 큰 위험: 광고 수익은 사업소득으로 신고 대상이 될 수 있습니다. 첫 입금 전에 세무 처리 방식을 확인합니다.

=== 부서: contract | 세아 (Contract Manager) ===
핵심 판단: 광고 정책 위반이 가장 큰 법적·계정 위험입니다. 아래 규칙을 지킵니다(Google 공식 정책 확인함).
- 보상형 광고는 이용자가 버튼을 눌러 원할 때만 보여줍니다. 광고 한 번마다 따로 동의해야 하며, 자동 재생은 안 됩니다.
- 광고 전에 "광고를 보면 +3초 다시 보기"처럼 보상을 분명히 알립니다.
- 광고를 거절해도 게임을 계속할 수 있어야 합니다.
- 보상은 게임 안 혜택만 줍니다. 돈이나 현금성 보상은 금지입니다.
- docs/AD_POLICY.md를 수정합니다: MEMORY 모드에서 이용자가 누른 "다시 보기"와 "이어하기"에만 보상형 광고를 허용하고, 플레이 중 강제 광고 금지 원칙은 유지합니다.
가장 큰 위험: 어린이 이용자. 초등학생 대상으로 홍보하면 아동 대상 광고 규정이 추가로 적용되므로, 출시 전 대상 연령을 정합니다.

=== 부서: ops | 태오 (Operations Manager) ===
핵심 판단: 일정과 순서를 확정합니다.
1. 1~2일: MEMORY 프로토타입(광고 없음).
2. 1주: 테스터 5~10명 테스트, 기록 수집.
3. 테스트 결과 회의: 미리보기 시간과 광고 지점 확정.
4. 통과하면: Android 패키징 → AdMob 테스트 광고로 보상 지급 확인 → 실제 광고 연결(대표 승인 후).
확인한 사실: 웹 게임용 Google 보상형 광고(H5 Games Ads)는 비공개 베타이며 승인이 보장되지 않습니다. 그래서 웹은 재미 검증용으로만 쓰고, 광고는 Android(AdMob)로 갑니다.
가장 큰 위험: 일정이 밀리면 테스트 없이 광고부터 붙이게 됩니다. 2단계를 건너뛰지 않습니다.

=== 종합: CEO Advisor ===
## 회의 요약
Number Maze가 쉽다는 문제를 "판을 5~10초 보여준 뒤 숫자를 가리고 기억으로 잇는" MEMORY 모드로 해결하고, 이용자가 원할 때만 보는 보상형 광고로 수익을 냅니다. 전원이 조건부 찬성했고, 순서는 재미 검증 → Android → 광고입니다.

## 쟁점
- 기억 방식: 숫자 가리기(채택) vs 경로 따라 그리기(제외)
- 광고 위치: 다시 보기·이어하기(채택) vs 플레이 중 강제 광고(금지)
- 광고 플랫폼: 웹 H5 Games Ads(비공개 베타, 승인 불확실) vs Android AdMob(채택)

## 대안 비교
| 항목 | 확정 내용 |
|---|---|
| 방식 | 숫자 가리기, 1과 목표 칸은 보임 |
| 미리보기 | 3×3=3초, 4×4=5초, 5×5=7초, 6×6=10초 |
| 레벨 범위 | v1은 3×3~6×6 |
| 실패 | 틀린 칸 3회 |
| 다시 보기 | +3초, 레벨당 1회 무료(프로토타입) |
| 광고 | 지금은 없음. 자리만 분리 |
| 비용 | 0원 |
| 통과 기준 | 테스터 절반 이상 "한 판 더" + 다시 보기 사용 기록 확인 |

아직 데이터가 있어야 정할 수 있는 것: 실제 재미, 광고 단가, 광고만으로 월 100만원 도달 여부, 7×7 이상 사용 여부.

## 대표 결정 선택지
- [A] MEMORY 모드 프로토타입을 광고 없이 1~2일 안에 만들고, 1주 동안 테스터 5~10명으로 검증한 뒤 광고를 결정한다 (추천·결론)
- [B] 프로토타입 없이 바로 Android 앱과 보상형 광고 작업부터 시작한다
- [C] MEMORY 모드를 보류하고 기존 CLASSIC에 별점·특수 칸을 먼저 추가한다
