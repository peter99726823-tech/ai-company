## 2. 실용성 문제 점검

| 문제 | 있었나 | 심각도 | 설명 / 조치 |
|---|---|---|---|
| 애니메이션만 하고 실제 업무 없음 | 없음 | — | 캐릭터 명령은 `useTaskDriver`가 저장된 업무 상태에서만 만듦 |
| 완료 표시인데 결과물 없음 | 없음 | — | 보고서 없이는 COMPLETED 전환 불가(`finalizeTask`) |
| 역할이 이름에만 의존 | 일부 | 중 | 역할 프롬프트는 구체적이나 직원별 **도구** 차이는 없음(모두 텍스트 작업) |
| 매번 프로젝트를 다시 설명 | **있었음** | 높음 | 프로젝트 정보만 들어가고 지난 결정·결과는 안 들어감 → **이번에 프로젝트 기억 추가** |

| 서버 종료 시 기록 소실 | 없음 | — | DB 저장, 진행 중이던 API 업무는 실패로 표시 |
| 상태와 캐릭터 불일치 | 있었음(수정됨) | 중 | 답을 기다리는 회의가 참석자를 붙잡던 문제 → 11/3 수정 |
| 게임 화면이 업무 관리에 불편 | **있었음** | 높음 | 메뉴가 흩어져 있었음 → **이번에 ⚡ 업무 보기(지시·진행·결정·결과물·비용) 추가** |

## 3. 이번에 구현한 것 (P0/P1 중 실용성 최우선)
1. **⚡ 업무 보기** (`components/WorkModal.tsx`, 상단 첫 버튼)
   - 한 칸에 자연어로 지시 → **자동 담당자 선정**(`domain/routing.ts`, 키워드 규칙이라 AI 호출 0회, 이유 표시, 바꾸기 가능) → 링크 버전은 Claude가 바로 작성, PC 버전은 API 실행기
   - 탭: 진행 중(처리·취소) / 결정·승인·실패(회의 결정, 승인·거절, 다시 시도) / 결과물 보관함(제목·내용 검색, 프로젝트·직원 필터, 💬 질문) / 사용량·비용(오늘·이번 달 API 비용, 직원별, 14일 그래프, Claude 자동 횟수)
2. **프로젝트 기억** (`server/work/service.projectMemory`): 프로젝트가 있는 업무·회의·대화 프롬프트에 최근 대표 결정 5개와 최근 결과 요약 6개를 자동 포함(최대 3,500자, 대화 1,500자)
3. **중복 업무 차단** (`createTask`): 같은 직원에게 같은 지시가 아직 열려 있으면 거부하고 기존 업무 ID를 알려줌
4. API: `GET /api/work/board`, `/api/work/reports`, `/api/work/usage` (PC·링크 공통)

## 4. 미구현과 이유
- **프로젝트 폴더 연결·코드 수정(Claude Agent SDK)**: 링크 버전은 브라우저 안에서만 돌아 PC 파일에 접근할 수 없습니다. PC 버전 실행기에 붙여야 하고, 파일 수정은 데이터 손실 위험이 있어 **아래 계획 승인 후** 진행합니다.
- **Claude 자동의 토큰·금액**: claude.ai 요금제 사용량은 페이지에 공개되지 않아 횟수만 기록합니다(지어내지 않음).
- **직원별 도구 권한**: 지금은 모든 직원이 텍스트만 생산하므로 의미가 없습니다. 파일·웹 도구가 생길 때 함께 설계합니다.
- **실제 Claude API 키 검증**: 이 환경에 키가 없어 가짜 API 서버로만 검증했습니다.

## 5. 다음 단계 계획 (승인 필요): 프로젝트 연결 + 승인 기반 코드 작업
PC 버전 전용. 순서대로 작게 진행합니다.
1. **작업 공간 등록**: 프로젝트마다 허용 폴더 1개(`projects.workspacePath`), 경로 밖·`.env`·비밀키 파일 읽기 금지 목록
2. **읽기 전용 분석**: 실행기가 허용 폴더의 파일 목록·내용을 읽어 코드 분석 보고서 작성(Claude API + 읽기 도구만)
3. **수정 제안 → 승인 → 적용**: AI는 변경안(diff)만 만들고 WAITING_APPROVAL로 멈춤. 대표가 diff를 보고 승인해야 git 브랜치에 적용, 테스트 명령 실행 결과를 보고서에 첨부. 삭제·대량 변경·`git push`·배포·결제·메시지 발송은 기본 차단
4. **Claude Agent SDK**: 3단계가 안정된 뒤, 허용 도구(Read/Edit/Bash 화이트리스트)와 작업 폴더를 고정한 에이전트로 교체
5. 각 단계마다 테스트: 허용 경로 밖 접근 거부, 승인 없이 파일 불변, 거절 시 원복, 실행 중 취소
