# AI 회사 시뮬레이터

AI 직원 9명이 픽셀아트 사무실에서 일하는 개인용 AI 회사 운영 시스템입니다.
목표는 직원이 실제 Claude AI로 업무를 수행하고, 그 진행 상황이 사무실 속 캐릭터의 행동으로 나타나게 하는 것입니다.

## 현재 단계: PHASE 1 완료 (픽셀 사무실 엔진)

| 단계 | 내용 | 상태 |
|---|---|---|
| PHASE 1 | 사무실 맵, 캐릭터 9명, 이동·충돌, 상태 애니메이션, 클릭, 게임 UI, DB 스키마 | ✅ 완료 |
| PHASE 2 | Claude API 연결, 업무 생성·실행, 보고서 저장, SSE 실시간 상태 | 다음 |
| PHASE 3 | 부서 간 전달, AI 회의, 승인 시스템 | |
| PHASE 4 | 반복 업무, 자동 모드, 비용 통제, 실패 복구 | |

PHASE 1에는 AI 업무 실행이 없습니다. 업무 지시 버튼은 비활성이고, 업무 로그에는 지어낸 기록을 넣지 않습니다.

## 실행 방법

필요: Node.js 20 이상 (22 권장)

```bash
npm install
```

```bash
npm run dev
```

브라우저에서 http://localhost:3000 을 엽니다. 첫 실행 때 `data/company.db`가 자동으로 생성됩니다.

프로덕션 모드:

```bash
npm run build && npm start
```

## 조작

- **직원 클릭:** 상세 창 (프로필, 상태, 업무, 전문 분야)
- **마우스 휠:** 확대·축소 / **드래그:** 이동 / **전체 보기**, **따라가기** 버튼
- **연출 속도 0.5x~4x:** 캐릭터 이동과 애니메이션 속도만 바뀝니다
- **개발자 도구 › 애니메이션 미리보기:** 9가지 동작(대기, 작업, 생각, 회의, 보고, 휴식, 오류, 승인 대기, 걷기)을 직접 확인합니다. 실제 업무가 아니라고 표시됩니다.

## 테스트

```bash
npm test
```

맵과 경로 단위 테스트입니다. 모든 지점의 도달 가능 여부, 벽·가구 비통과, 방 9개를 검사합니다.

```bash
npm run typecheck
```

```bash
npm run e2e
```

브라우저 E2E 검사입니다. 서버가 3000번 포트에서 실행 중이어야 하며, 스크린샷은 `e2e/out/`에 저장됩니다.
