# AI 회사 시뮬레이터

AI 직원 12명(전략기획실·개발실 각 3명)이 픽셀아트 사무실에서 일하는 개인용 AI 회사 운영 시스템입니다.
목표는 직원이 실제 Claude AI로 업무를 수행하고, 그 진행 상황이 사무실 속 캐릭터의 행동으로 나타나게 하는 것입니다.

## 현재 단계: PHASE 2 (실제 AI 업무 실행)

| 단계 | 내용 | 상태 |
|---|---|---|
| PHASE 1 | 사무실 맵, 캐릭터 9명, 이동·충돌, 상태 애니메이션, 클릭, 게임 UI, DB 스키마 | ✅ 완료 |
| PHASE 2 | Claude API 연결, 직원별 프롬프트, 업무 생성·실행·취소·재시도, 보고서 저장, SSE 실시간 상태, 비용 기록 | ✅ 구현 · 실제 API 검증은 키 필요 |
| PHASE 3 | AI 회의·결정·후속 업무, 무료 붙여넣기 방식, 직원과 1:1 대화, 보고서 결재(승인·수정 요청·추가 분석·전달·프로젝트 반영·종료) | ✅ |
| PHASE 4 | 운영 모드(수동·반자동·자동), 반복 업무 스케줄, 업무 제안·승인, 하루 자동 실행 한도, 재무 거래내역, 프로젝트 관리, 계약서 파일, 백업·복원 | ✅ |

### 회의 (주제를 주면 부서별로 답하기)
이미 받은 회의 답변이 있으면 **회의 소집 › 📋 받은 답변 바로 붙여넣기** 탭에 통째로 붙여넣으세요. 참석 부서를 답변에서 찾아 회의록으로 바로 저장합니다.

상단의 **회의 소집** → 주제와 참석 부서 선택 → 참석자들이 회의실로 이동 → 부서별 의견 → CEO Advisor 종합과 결정 선택지 → 대표가 결정하면 후속 업무가 담당 직원에게 등록됩니다.
부서별 의견은 AI가 한 번의 응답에서 각 부서 역할로 차례대로 작성합니다(앞 발언을 보고 이어 말함). 참석자가 빠진 답은 저장하지 않습니다.

### 회의록 칸
상단의 **📄 회의록**에서 끝난 회의를 한곳에서 봅니다. 회의 요약, 결정 선택지, 대안 비교, 대표 결정(또는 결정 대기)이 보이고, 검색과 "결정 대기/완료" 필터가 있습니다. **회의록 열기**로 부서별 발언 전체와 결정 기록 화면으로 갑니다.
회의가 끝나면 발언을 차례로 재생한 뒤 모두 자기 부서 자리로 돌아갑니다. 답을 기다리는 붙여넣기 회의는 회의실 창을 열어 둔 동안만 참석자를 회의실에 모읍니다.

### 직원과 대화, 보고서 결재
- 직원 상세 창의 **대화하기**: 직원별·프로젝트별로 대화가 따로 저장되고, 최근 대화가 다음 답변의 맥락으로 들어갑니다.
- 보고서 창의 **대표 결재**: 승인, 수정 요청, 추가 분석, 다른 직원에게 전달, 프로젝트에 반영, 업무 종료. 수정 요청·추가 분석·전달은 그 보고서를 입력 자료로 붙인 후속 업무를 만들고, 모든 결정은 이벤트 로그와 보고서 이력에 남습니다.

### 아이디어 메모함과 파일 첨부
- **아이디어:** 상단의 **아이디어** 버튼에서 떠오른 생각을 한 줄씩 적어 둡니다. 각 아이디어를 **서진에게 검증 맡기기**(GO/PIVOT/HOLD/STOP 보고서) 또는 **회의 열기**로 바로 넘기고, 새 아이디어·검토 중·진행·보류·폐기로 관리합니다.
- **파일·폴더 첨부 (📎 파일, 📁 폴더, 또는 끌어다 놓기):** 업무 지시 양식, 회의 소집 창, 대화창에 최대 5개 첨부합니다. 텍스트(.txt .md .csv .json), **HTML(소스 그대로)**, 코드(.js .css .ts .py 등), PDF(글자 추출)를 읽습니다. **폴더**는 첨부 1개로 묶여 "폴더 구조 목록 + 각 파일 내용"이 되고, node_modules·.git·빌드 폴더는 빼며, 이미지·압축파일 등은 목록에만 표시합니다. 파일당 3만 자, 폴더당 8만 자, 합계 10만 자까지이고 넘으면 앞부분만 쓰고 표시합니다. 스캔 PDF·한글·워드·엑셀은 claude.ai에 직접 첨부하거나 내용을 복사해 붙여넣으세요.

### 자율 운영과 관리 (설정 · 프로젝트 · 재무)
- **설정 › 운영 모드:** 수동(지시한 것만) / 반자동(반복 업무와 보고서의 추천 업무가 제안으로 올라와 승인 후 진행) / 자동(미리 등록한 반복 업무를 하루 한도까지 스스로 시작). 기본은 수동입니다.
- **설정 › 반복 업무:** 담당 직원, 내용, 매일·매주·매월, 시각을 등록합니다. PC 버전은 실행기가 30초마다 확인해서 브라우저를 닫아도 진행되고, 링크 버전은 페이지가 열려 있을 때만 확인합니다.
- **제안 승인:** 오른쪽 아래 '오류 · 승인 요청'이나 직원 창에서 승인·거절합니다.
- **프로젝트:** 설명·목표·단계·다음 계획·담당·예산·매출을 편집하고, 프로젝트별 업무·보고서·회의록을 모아 봅니다. 업무를 지시할 때 이 정보가 자동으로 전달됩니다.
- **재무:** 거래내역을 입력합니다(실제와 시뮬레이션을 분리해 합계). '지호에게 분석 요청'을 누르면 내역이 지시문에 자동으로 붙습니다.
- **계약서 파일:** 업무 유형 '계약서 파일 분석'에서 📎로 .txt .md .pdf 파일을 첨부합니다.
- **백업:** 설정 › 백업 파일 저장(JSON). 링크 버전은 화면에서 복원, PC 버전은 앱을 끄고 `npm run db:restore -- 파일.json`.

### 비용 없이 쓰기: Claude 자동(링크 버전) · 붙여넣기
업무와 회의는 아래 방식 중 하나로 처리합니다.
- **Claude 자동 (링크 버전, claude.ai 안에서 열 때):** 회의를 올리면 Claude가 바로 부서별 의견과 종합을 작성해 저장합니다. API 키 없이 로그인한 claude.ai 계정의 사용량을 씁니다. 처음 한 번 허용 창이 뜨고, 거절하거나 쓸 수 없으면 붙여넣기 방식이 그대로 남습니다. 진행 중에 창을 닫으면 중지됩니다.
- **붙여넣기 (무료):** 앱이 만든 지시문을 [claude.ai](https://claude.ai)에 붙여넣고, 받은 답을 앱에 다시 붙여넣습니다. API 키가 필요 없고 API 비용이 0원입니다. 키가 없으면 이 방식이 기본입니다.
- **API 자동:** 실행기가 Claude API를 직접 호출합니다. `.env.local`에 키가 있어야 하며 사용량만큼 비용이 듭니다.

### 업무가 처리되는 흐름 (API 자동)
직원 클릭 → 업무 지시 → DB에 `QUEUED`로 저장 → 실행기(워커)가 선점 → 캐릭터가 책상으로 이동 → Claude 스트리밍 호출(`RUNNING`, 말풍선은 실제로 작성 중인 보고서 단락) → 보고서·비용 저장(`COMPLETED`) → 캐릭터가 대표실에서 보고 → 대표 알림.
API 키가 없거나 호출이 실패하면 `FAILED`와 실제 사유가 표시되고, 보고서를 만들지 않습니다.

## 링크 버전 (설치 없이)

`lite/`는 같은 코드를 브라우저 안에서만 돌리는 버전입니다. SQLite를 WebAssembly(sql.js)로 돌리고, 업무와 회의는 붙여넣기 방식만 지원합니다.

```bash
npm run lite:build
```

`lite/dist/index.html` 한 파일로 빌드됩니다. claude.ai 아티팩트로 올리면 기록이 아티팩트의 비공개 저장소에 자동 저장되고, 그 밖에서 열면 브라우저(localStorage)에 저장됩니다. 검사는 `node e2e/lite.mjs`, Claude 자동과 상단 바는 `node e2e/lite-auto.mjs`(claude.ai의 Claude 호출을 테스트용으로 흉내 냄)로 합니다.

## 실행 방법 (PC, API 자동 실행 포함)

필요: Node.js 22 이상

```bash
npm install
```

API 키 설정 (API 자동 방식에만 필요, 붙여넣기 방식은 키 없이 됩니다):

```bash
cp .env.example .env.local
```

`.env.local`을 열어 `ANTHROPIC_API_KEY=`에 키를 넣습니다. 자세한 내용은 [docs/SETUP.md](docs/SETUP.md).

```bash
npm run dev
```

웹 서버와 업무 실행기가 함께 켜집니다. 브라우저에서 http://localhost:3000 을 엽니다. 첫 실행 때 `data/company.db`가 자동으로 생성됩니다.
실행기만 따로 켜려면 `npm run worker`, 웹만 켜려면 `npm run web:dev`.
터미널을 닫으면 실행기도 꺼지고, 진행 중이던 업무는 실패로 기록됩니다.

프로덕션 모드:

```bash
npm run build && npm start
```

## 조작

- **직원 클릭:** 상세 창 (프로필, 상태, 업무, 전문 분야)
- **마우스 휠:** 확대·축소 / **드래그:** 이동 / **전체 보기**, **따라가기** 버튼
- **연출 속도 0.5x~4x:** 캐릭터 이동과 애니메이션 속도만 바뀝니다
- **개발자 도구 › 애니메이션 미리보기:** 9가지 동작(대기, 작업, 생각, 회의, 보고, 휴식, 오류, 승인 대기, 걷기)을 직접 확인합니다. 실제 업무가 아니라고 표시됩니다.

## 테스트

```bash
npm test
```

맵·경로 테스트와 업무 실행기 테스트입니다. 실행기 테스트는 **테스트 전용 가짜 API 서버**(`e2e/mock-anthropic.mjs`)를 씁니다. 실제 Claude를 호출하지 않으며 비용이 들지 않습니다.

```bash
npm run typecheck
```

```bash
npm run e2e
```

브라우저 E2E 검사입니다. 추가로 `node e2e/pc-phase4.mjs`(실행기의 반복 업무·백업), `node e2e/pc-attach.mjs`(PDF 첨부), `node e2e/lite.mjs`(링크 버전 전체)가 있습니다. `phase1`은 3000번 포트에 서버가 떠 있어야 하고, `phase2`(첫 업무 시나리오 14단계)는 빌드된 앱·실행기·가짜 API를 스스로 띄웁니다. 먼저 `npm run build`가 필요합니다. 스크린샷은 `e2e/out/`에 저장됩니다.
